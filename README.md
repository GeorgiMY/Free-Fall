<h1 align="center">Free Fall</h1>

## Free Fall is an educational website that shows various gravitational phenomena with the help of simulations.

Main goals:
- To increase students' interest in the subjects: man and nature and physics and astronomy.
- To support the learning of students in the classes of man and nature - 5th and 6th grades, physics and astronomy - 7th, 8th, 9th and 10th grades, through the study of gravity.
- To support teachers teaching the following subjects: man and nature, physics and astronomy and mathematics, by allowing them to visually show students how gravity works

## Technological tools used:
- Development and coding environment – ​​Visual Studio Code
- Programming languages
- HTML5
- CSS3
- JavaScript
- JavaScript libraries used:
  - P5JS - Allows vector calculation and easier creation and movement of objects on the screen
  - SmtpJS - Allows contact by sending an email.
  - JQuery - Miscellaneous things
